# Ónix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vertical slice de Ónix (clon web Obsidian multi-usuario) desplegado en Dokploy.

**Architecture:** App Router + `lib/vault.ts` (notas, por workspace-root) + `lib/system-store.ts` (usuarios/workspaces/grants en JSON) + sesiones JWT en cookie + APIs por workspace + UI shadcn (Operate, dark-first).

**Tech Stack:** `next@16.4.5` + TypeScript `7.0.2` + `tailwindcss@4.3.5` + shadcn (CLI `4.23.0`, neutral), `@uiw/react-codemirror@4.25.12`, `react-markdown@10.1.0` + `remark-gfm@4.0.1`, `gray-matter@4.0.3`, `next-themes@0.4.6`, `jose`, `bcryptjs`, `vitest@5.1.0` (versiones fijadas de npm el 2026-11-09; el ejecutor usa estas exactas).

**Spec:** `docs/superpowers/specs/2026-11-09-onix-design.md`

## Global Constraints

- `src/lib/vault.ts` es la única capa que toca notas; recibe el root del workspace.
- Toda ruta se confina a su root (anti `..`).
- Límite por nota: 1 MB.
- Sin sesión válida → 401; sin grant sobre el workspace → 403; sin secreto de sesión → todo 401.
- Vault compatible con Obsidian real (frontmatter + wikilinks intactos).

## Review Focus

- Título con `../` o absoluto sale del root → 400/404, nunca lee fuera.
- Nota >1 MB → 413, no OOM.
- `[[nota inexistente]]` → preview la marca por crear, no rompe el render.
- Usuario con sesión válida pero sin grant pide el workspace → 403, sin filtrar existencia.
- JWT manipulado o expirado → 401 y a login, sin medias tintas.
